# Resource Library Benchmark Audit

**Benchmark:** https://mavgpt.ai/resources/claude-language-tutor-setup-2026  
**Reviewed:** July 14, 2026

## What The Benchmark Gets Right

1. The promise is immediate and specific.
2. The useful method is visible on the page instead of hidden entirely behind a form.
3. The resource has category, read-time, date, setup steps, requirements, and practical starter commands.
4. The download prompt appears near the top and after the reader has seen the method.
5. A copyable prompt lets the reader experience value before downloading the PDF.

## Gaps To Improve

1. The download is a direct PDF link, so the page does not create an owned subscriber relationship.
2. The page is primarily a long article; it has little visual proof of the finished operating artifact.
3. There is no package manifest, release version, change log, compatibility statement, or validation status.
4. The prompt is useful but remains one large instruction block rather than a portable skill with deterministic controls.
5. There are no sample inputs, expected outputs, failed examples, or independent verification step.
6. The resource does not separate what AI prepares from what the user must approve.

## Shetty's Desk Improvement Standard

Every Shetty's Desk resource page should include:

- a visible promise and approved visual in the first viewport;
- a still and motion preview of the real artifact;
- the operating problem and decision boundary;
- a five-step workflow;
- package contents and expected outputs;
- synthetic sample data;
- a version, update date, and validation status;
- an email-gated signed download;
- an installable skill plus deterministic scripts where calculations matter;
- a clear human approval boundary;
- a short privacy and consent statement.

## Phase 1 Decision

Use the benchmark's clarity and progressive disclosure, but make the downloadable package runnable, versioned, and reviewable. The page should demonstrate enough value to earn the email rather than use the form as a blind gate.
