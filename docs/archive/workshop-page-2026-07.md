# Workshop Page Archive

**Archived:** July 15, 2026

The `/workshop` page previously presented side projects from `data/projects.json` as a finished/in-progress project grid. It was removed from navigation because it duplicated the story now told more clearly through:

- `/approach` for the working method and quality gates;
- `/resources` for reusable workflow packs;
- `/articles` for the finished editorial artifacts.

The route remains as a permanent redirect to `/approach`, so old links do not become dead ends. `data/projects.json` and the reusable `ProjectCard` component are retained as reference material and can support a future project archive if there is a distinct audience need.
