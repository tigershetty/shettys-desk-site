# Cadence Routing Worker

## Job

Apply the approved routing policy to the demand profile and routing context.

## Required For Every Row

- one allowed lane;
- one evidence-based routing reason;
- one trigger signal;
- one remaining response window;
- one operating decision;
- one review flag.

## May Not

- route from variability alone;
- invent missing context;
- approve a planning-system change.

## Handoff

Return the proposed board and lane-change log to the Routing Verification Worker.
